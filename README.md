# Edu Learning Portal

React (Vite + TypeScript) portal for **admins** and **teachers**.

## Roles

| Role | Access |
|------|--------|
| Admin | Add admins, add teachers, staff directory |
| Teacher | Add content, quizzes, past papers, memos |

Students cannot sign in to this portal.

## Setup

```bash
npm install
npm run dev
```

App: `http://localhost:5173`

Demo accounts (password `Password123!`):
- Admin: `admin@edu.na`
- Teacher: `teacher@edu.na`
